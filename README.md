# REV — Red de Emergencia Valle

Plataforma de **gestión de emergencias municipales**: incidentes, zonas de riesgo, logística de recursos y dashboard de despacho.  
Lema de producto: *conectividad que salva vidas*.

## Problema
Coordinar respuesta ante emergencias exige visibilidad operativa (qué pasó, dónde, con qué recursos) en tiempo crítico.

## Capacidades
- Registro y seguimiento de incidentes
- Zonas de riesgo (componente geo)
- Gestión de recursos / logística
- Dashboard de despacho

## Stack
- Java 21 / Spring Boot (microservicios)
- API Gateway · autenticación JWT / Keycloak
- PostgreSQL + PostGIS
- Frontend React (Vite)
- Docker
